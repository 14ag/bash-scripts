## Your Challenge
Write a Bash script based on the following requirements:

- Creates 25 empty (0 KB) files.
- The file names should be [name][n] where [name] is your name and [n] is an integer. (n, n+1, n+2...)
- each time script is run, it creates the next batch of 25 files with increasing numbers starting with the last [n] that already exists.
